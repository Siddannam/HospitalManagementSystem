# HospitalManagementSystem

All logic is implemented within a single class file. For scalability, you can separate each class (`Patient`, `Appointment`, etc.) into its own file.

---

## 🚀 Features

### 1. Patient Management
- Register new patients with ID, name, age, and disease.

### 2. Appointment Scheduling
- Schedule appointments for registered patients with doctors.

### 3. EHR Management
- Add electronic health records (diagnosis and treatment) for patients.

### 4. Billing
- Generate bills for patients with associated costs.

### 5. Inventory Management
- Add or update hospital inventory items and their quantities.

### 6. Staff Management
- Add new staff with IDs, names, and roles.

---

## 🛠️ Technologies Used

- **Language:** Java (JDK 8+)
- **Input Handling:** Java `Scanner`
- **Data Storage:** In-memory using `ArrayList`
